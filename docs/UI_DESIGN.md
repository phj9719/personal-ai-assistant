# UI 설계 v0.1

ChatGPT 유사 채팅 중심. 기본 진입 `/assistant`. PC 왼쪽 사이드바, 모바일 하단 메뉴(AI 비서/홈/일정/할 일/전체)와 전체 메뉴 drawer. 한국어, 라이트/다크, 반응형.

| 메뉴 | URL | 화면 |
|---|---|---|
| AI 비서 | /assistant | 새 채팅, 채팅 목록, 메시지, 입력창, 확인 카드 |
| 대시보드 | /dashboard | 오늘 일정·할 일·지출·재고·공과금·학습 요약 |
| 일정 | /schedule | 월간 캘린더, 상세·등록 |
| 할 일 | /tasks | 상태별 목록, 완료 |
| 가계부 | /finance | 수입·지출 내역, 고정 지출 관리, 저축 및 투자, 결제수단 관리, 월별 통계 탭 |
| 냉장고 | /inventory | 보관 장소 필터, 수량, 소비기한 |
| 공과금 | /utilities | 실제·참고용 공통 등록, 주차비·고지서 차액, 거주 기간 경고, 항목별 전년 비교, 연간 동일 월 비교, 표·CSV 가져오기 |
| 메모 | /knowledge | 검색, 목록, 편집 |
| 개발·학습 | /learning | 프로젝트·목표·학습 기록 탭 |
| 생활 분석 | /analytics | 지출·완료율·학습·활동 통계 |
| 설정 | /settings | 테마, 모델, 연결 상태, 기억 관리 |
| 로그인 | /login | 인증 |

공통 컴포넌트: AppLayout, Sidebar, MobileNav, Header, PageHeader, DataTable, SearchFilter, FormDialog, ConfirmDialog, StatCard, ChatMessage, ChatInput, Loading, EmptyState, Toast. 모바일 표는 카드 또는 가로 스크롤로 대응. 키보드 접근성, 포커스, 오류 안내 포함.

초기 모든 화면은 가상 데이터로 먼저 구현하되 실제 데이터와 명확히 구분한다. 기능 연결 후 미구현 버튼은 비활성화/표시하고 성공한 것처럼 보이지 않게 한다. 파일 첨부·마이크·고급 알림은 후속이다. 화면 디자인과 입력 항목은 실사용하며 수정한다.

가계부의 **정산·대납 관리** 탭에서 일반 정산, 대납금 관리, 입금 이력, 미수금 현황을 전환한다. 결제·참석자·상환 회차 입력은 좁은 화면에서 한 열로 줄어든다. 대시보드는 전체 미수금과 이번 달 예정 입금액을 표시한다.

사이드바의 **야구** 메뉴는 야구 대시보드, 직관 일정, 예매 관리, 직관 기록, 직관 통계, 데이터 가져오기·내보내기를 제공한다. 일정에는 월간·주간·목록 캘린더를 제공하며 메인 일정에 연결된 항목에서는 원본 야구 경기 상세를 연다. 기본 응원팀은 롯데 자이언츠이며 설정에서 변경한다.

채팅 기록 메뉴에서 대화별 제목 변경과 삭제를 제공한다. 전체 삭제는 `전체 삭제` 확인 문구를 요구하며, 선택한 채팅이 삭제되면 새 채팅으로 이동한다. 모바일 입력창에는 줄바꿈 버튼이 있으며, 실패한 질문 옆에는 같은 메시지를 다시 시도하는 버튼이 표시된다.

사이드바의 일상 기록은 대시보드, 타임라인, 캘린더, 돌아가며 결제, 활동 통계를 제공한다. 가계부의 구독 서비스 관리에서는 대시보드, 서비스 목록, 결제 예정·이력, 비용 통계를 전환한다. 두 메뉴의 가져오기는 Excel·Markdown·CSV 정상 행과 오류 행을 미리 보여 주며, 데이터는 JSON으로 내보낼 수 있다.

공과금은 기본 비교 기준을 주차비 제외로 표시하고 고지서 원본 기준으로 전환할 수 있다. 비교 표는 PC·모바일에서 항목, 전년·올해 값, 증감, 증감률을 한 화면에 표시한다. 거주 기간 밖 실제 청구는 등록·수정 화면 또는 가져오기 미리보기에서 확인한다.

# 요구사항 v0.1

목표: 실제 매일 사용할 개인 AI 비서, AI 개발 역량 향상. 전체 기본 화면 우선, 실사용 후 점진 개선. 6개월 계획은 폐기하고 2~3주 초기 목표는 참고만 한다(가용 시간 미확정).

| 모듈 | 초기 범위 | 이후 후보 |
|---|---|---|
| 일정 | CRUD, 월간 캘린더 | 반복, 알림, 충돌 안내 |
| 할 일 | CRUD, 상태·마감·완료 | 우선순위 추천, 반복 |
| 가계부 | 수입·지출 CRUD, 분류, 월 합계 | 예산, 정기 지출, CSV |
| 냉장고 | 식품 CRUD, 수량, 단위, 보관, 소비기한, 재고 이력 | 요리 추천, 구매 목록, 알림 |
| 공과금 | 청구월, 항목별 금액·사용량·기간, 납부 상태, 월별 비교 | 예측, OCR |
| 메모 | 제목·본문·태그 CRUD, 키워드 검색 | RAG, 첨부, 의미 검색 |
| 개발·학습 | 프로젝트, 학습 목표·기록, 진행률 | 학습 로드맵, 이슈 관리 |
| 생활 분석 | 기존 데이터 집계, 간단한 활동 기록 | AI 주간·월간 리포트 |

공통: 로그인, AI 채팅, 대시보드, 설정. 전체 12개 주요 화면. 채팅방 생성·목록·재개, 최근 메시지 문맥, 명시적 기억 저장·조회·삭제 기본 지원. 대화 요약 및 자동 장기 기억은 후속.

AI 초기: 자연어 조회 및 기본 등록 도구를 8개 모듈에 점진 연결. 분석 모듈은 조회 중심. 변경 전 확인, 부족한 값은 질문, 성공은 실행 후 표시. 여러 모듈을 한 번에 쓰는 기능은 후속이지만 중복 방지와 트랜잭션 구조는 처음부터 고려.

연동 후보: 식품 구매→가계부, 공과금 납부→가계부(중복 방지), 프로젝트→할 일, 학습→메모. 초기에는 직접 연결하거나 명시적 선택으로 연동; 복합 AI 자동화는 후속.

비기능: 한국어, PC·모바일, 다크/라이트, 개인 데이터 로컬 저장, 인터넷 직접 포트 공개 금지, 수동 CRUD 독립 동작, 데이터 백업 및 복구 검증. 외부 AI API, 중국 기업 모델, 공개 회원가입, 외부 캘린더·카드 자동 수집은 초기 제외.

## 관리비·가스비 상세

전기·수도 사용량과 요금, 공동 전기료, TV 수신료, 기본 관리비, 주차비, 고지서 원본 합계 및 비고를 청구월별로 관리한다. 실제·참고용 모두 같은 양식에서 등록하며, 같은 달의 가스비와 사용 기간도 함께 입력할 수 있다. 가스비만 별도로 등록할 수도 있다. 공동 전기료는 음수를 허용하고 주차비는 0 이상이다. 주차비는 확인용 항목으로 기록하며, 확인된 0원과 미입력을 구분한다. 고지서 합계와 기타 입력 항목의 세부 합계 차액을 표시한다.

본인이 납부한 청구는 입주월·퇴거월과 일부가 겹치는 가스 사용 기간을 허용한다. 거주 기간에 전혀 겹치지 않으면 실제/참고용을 사용자가 결정하고, 실제 청구로 선택한 경우 확인 후 저장한다. 거주 기간 변경으로 저장된 유형을 재분류하거나 납부액을 일할 계산하지 않는다. 참고용 내역은 가계부, 고정지출 실제 납부·현금흐름, 개인 누적 및 평균에서 제외한다.

전년 동월은 실제 청구를 우선하며, 없으면 참고용 청구를 자동 사용한다. 항목별 전년도·올해 값과 증감량·증감률을 표시한다. 0을 기준으로 한 증감률과 미확인 값은 계산하지 않는다. 관리비 비교·통계·그래프는 입력한 고지서 합계 기준이다. 주차비를 입력하지 않아도 고지서 합계를 비교할 수 있다. 총 주거비는 고지서 합계와 별도 가스비를 합산한다. 연간 비교 합계는 양쪽 연도에서 고지서 합계가 확인된 동일 월만 합산한다.

연도·월·데이터 유형 필터, 두 연도의 월별 그래프와 유형별 연도 추이를 지원한다. Excel TSV, Markdown 표 및 UTF-8 CSV는 머리글을 기준으로 가져온다. 데이터 유형 일괄 지정을 지원하며 예전 표도 읽을 수 있다. 새 표의 유형을 생략한 행은 참고용으로 저장하고, 같은 달에 기존 두 유형이 모두 있으면 유형을 직접 지정한다. 기존 청구를 수정할 때 별도 확인이 필요하다. 빈 셀은 미확인으로 저장하며 표에 없는 열은 기존 값을 유지한다. 천 단위 쉼표, 천 단위 접미사 `k`, `kWh`, `㎥`를 지원한다. 수도 사용량의 `t`는 1㎥로 읽는다. CSV에서 쉼표가 든 값은 따옴표로 감싼다.

## 가계부 고정 지출

결제수단 등록 시 유형과 은행·카드사는 필수이며 별칭은 선택이다. 별칭이 있으면 기관명과 함께 표시하고, 기관명과 같거나 비어 있으면 기관명만 표시한다.

월별 고정 지출은 활성 설정 중 적용 기간과 겹치는 항목을 사용자 요청으로 생성한다. 날짜가 있는 경우 해당 월의 말일과 월 안의 적용 기간에 맞추며, 대략적인 예정일과 날짜 미지정도 지원한다. 이미 만들어진 예정·납부 내역은 설정 수정이나 삭제 후에도 유지된다. 일할계산은 하루 금액에 이자 계산 시작일·종료일을 모두 포함한 일수를 곱하고, 월별 기록에서 최대 366일의 계산 기간을 조정할 수 있다.

예정액은 청구월, 실제 유출은 납부일 기준이다. 실제 납부액을 기록한 항목만 소비·저축·투자 유출에 반영한다. 직접 기록한 일반 거래와 저축·투자를 각각 합산하며, 전체 자금 유출에는 저축·투자를 포함하고 일반 소비에서는 제외한다. 관리비 또는 도시가스의 본인 고지액을 연결한 미납 건은 고지액을 남은 예정액에 우선 사용한다. 같은 납부 건은 고정 지출에서 기록하며 수입·지출 탭에 또 등록하지 않는다.

## 정산·대납

일반 정산은 참석자를 직접 입력하고 차등 부담금을 기본으로 한다. 균등 정산은 사용자 포함 인원수로 나눈 뒤 지정 단위 아래를 절사하고 본인이 차액을 부담한다. 한 정산에 여러 결제를 기록하며, 모든 부담금의 합이 결제 원금과 일치해야 한다. 입금은 부분·복수 건을 지원하고 취소 시 상태와 미수금을 다시 계산한다.

대납은 카드 할부 개월과 상대방 상환 기간을 별도 관리한다. 정기 계획의 매월 예정일은 시작일의 일자를 기준으로 하며 짧은 월은 말일을 사용한다. 금액 미정 회차는 미정 건수로 표시한다. 입금·잔액 조정은 날짜가 빠른 확정 회차부터 차감한다. 면제와 본인 부담 전환은 미수금을 줄이고 조정월의 본인 소비로 반영한다.

원본 지출·수입은 보존하고 정산에 연결한 경우 개인 월별 집계에서 한 번만 반영한다. 소비는 결제월의 본인 부담 및 조정월의 조정 금액이다. 카드 승인은 현금 유출에 포함하지 않고, 실제 등록한 카드대금 출금만 포함한다. 정산 입금은 일반 수입과 분리한다.

## 야구

경기 결과, 직관 예정·실제 관람, 예매 상태는 각각 독립적이다. 날짜가 지나도 관람을 자동 확정하지 않는다. 우천·폭염·노게임·기타 취소는 승패에서 제외하지만 실제 방문으로 표시한 경우 방문 횟수에는 포함한다. 강우콜드의 확정 스코어는 결과에 포함한다. 실제 관람의 승률은 승 ÷ (승 + 패)이며, 무승부는 연승·연패를 끊는다.

선예매와 일반 예매는 서울 시각으로 저장한다. 앱 알림은 설정한 분 전부터 예매 시작까지 조회할 수 있다. 외부 전송, 자동 일정 수집, 티켓 자동 예매 및 굿즈 관리는 개발 범위에서 제외한다.

## 채팅 기록과 오류 처리

Enter는 전송, Shift+Enter는 줄바꿈이다. 한글 IME 조합 중에는 단축키가 전송을 실행하지 않는다. 이전 대화에서 제목을 변경하거나 확인 후 개별·전체 기록을 삭제할 수 있다. 명시적으로 저장한 AI 기억은 별도로 보존한다. AI 오류는 연결·준비 중·타임아웃 등을 구분하고, 사용자가 기존 질문을 다시 시도할 수 있게 한다.

## 일상 기록, 돌아가며 결제 및 구독

일상 기록은 날짜와 제목만 필수다. 시작과 종료 시간으로 소요 시간을 계산하며, 완료 표시한 일정·할 일, 학습 및 실제 직관은 원본 조회로 타임라인에 표시한다. 돌아가며 결제는 일반 가계부와 분리한다. 실제 마지막 결제자와 순서상 마지막 참여자를 구분하고, 적립 수단과 순서 밖 결제는 차례를 넘기지 않는다. 결제 금액 미입력은 평균에서 제외하고 확인한 0원은 포함한다.

구독의 기본 날짜는 최초 결제일이다. 월·연 주기는 해당 일이 없는 달에 말일로 맞추고 이후 달에는 최초 기준일을 다시 사용한다. 수동 조정은 가장 가까운 명목 회차 한 건만 이동한다. 무료 체험이 자동 갱신되는 경우 체험 종료일부터 예상 비용을 계산한다. 예정액, 실제 원화 결제액, 월평균 환산액은 별도 집계한다. 원화 금액과 환율이 모두 없는 외화 실결제는 미확정으로 보인다.
